CAX SSG generates pure static HTML in the `site/` directory. Deploy to GitHub Pages with GitHub Actions, Vercel with `vercel --prod ./site`, Netlify with drag-and-drop, or any static hosting provider.

No runtime, no dependencies, no lock-in. Just your metadata.
